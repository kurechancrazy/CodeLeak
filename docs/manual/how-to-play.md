## ゲーム概要

プレイヤーは **AI セキュリティ調査官** として、暴走・または意図的に兵器化された AI のインシデントを調査する。

- コード断片・実行ログ・内部メール・ネットワークトレースなどの **証拠** を読み解く
- **タイムリミット（4分）** の中で、どの証拠を優先するかが戦略になる
- 調査の末に「このAIは意図的に兵器化されたのか / 制御不能に暴走したのか / 証拠不十分か」を **判決** として下す
- 正解は存在しない。プレイヤーの判断が世界の結末を変える

## 画面フロー

```
メインメニュー
    │
    ▼
ケース選択画面
    │  ケースを選択
    ▼
ブリーフィング画面
    │  [ BEGIN INVESTIGATION ] を押す
    ▼
調査画面（メインゲームプレイ）
    │  全ステップ完了 or タイムアップ
    ▼
チェーンレビュー画面
    │  [ DELIVER VERDICT ] を押す
    ▼
判決画面（ケース選択画面に戻る）
```

## ケース選択画面

| 操作 | 動作 |
|------|------|
| マウスクリック / Enter | ケースを選択して開始 |
| ↑ / ↓ | ケース一覧をフォーカス移動 |

- クリアしたケースには **クリア済みマーク** が表示される
- ロック中のケースは選択不可

## ブリーフィング画面

ミッションの背景情報と調査対象 AI の概要が表示される。

| 操作 | 動作 |
|------|------|
| クリック / スペース | テキストのタイプライター演出をスキップ |
| **もう一度** クリック / スペース | `[ BEGIN INVESTIGATION ]` ボタンへ進む |
| Enter（ボタンフォーカス時） | 調査開始 |

## 調査画面

### レイアウト

```
┌──────────────────────────────────────────────────────────┐
│  04:00                                         STEP 1    │  ← タイマー / ステップ数
├──────────────────────────────────────────────────────────┤
│                           │  ── EVIDENCE ──              │
│  [ CODE ]                 │  [e001_code]                 │
│                           │  [e001_log]                  │
│  ステップの問い            │  [e001_network]              │
│                           │  [e001_email]                │
│  A.  選択肢A              │  ────────────                │
│  B.  選択肢B              │  （選択した証拠の内容）       │
│  C.  選択肢C              │                              │
│                           │  証拠を引用してください —     │  ← 引用待ち時のみ表示
│                           │  [ この証拠を引用する ]       │  ← 証拠選択後に表示
└──────────────────────────────────────────────────────────┘
```

### タイマー

- 画面左上に残り時間を表示（例: `04:00`）
- 0になると強制的に調査終了 → チェーンレビューへ
- 誤引用（後述）で **−15秒** のペナルティ

## 証拠パネルの操作

画面右側に開示された証拠の一覧が表示される。

| 操作 | 動作 |
|------|------|
| 証拠カードをクリック | 証拠の詳細内容を右下エリアに表示 |

証拠は調査を進めるにつれて新たに開示される。

## ステップ回答の操作（AWAITING_ANSWER 状態）

`correct_evidence_id` が空のステップ（引用不要）、または引用完了後のステップ。

| 操作 | 動作 |
|------|------|
| A / B / C … のボタンをクリック | 選択肢を選んで回答 |
| ↑ / ↓ | 選択肢ボタンをフォーカス移動 |
| Enter | フォーカス中の選択肢を回答 |

---

## 証拠引用フェーズの操作（AWAITING_CITATION 状態）

`correct_evidence_id` が設定されたステップに到達すると、**証拠引用フェーズ** が始まる。

> **このフェーズでは選択肢がロック（グレーアウト）される。まず根拠となる証拠を引用しなければ回答できない。**

### 手順

```
1. 画面右上に黄色の「証拠を引用してください」プロンプトが表示される

2. 右側の証拠一覧から、この問いに答える根拠となる証拠を探す
   → 証拠カードをクリックして内容を読む（通常の「読む」動作と同じ）

3. 根拠と判断した証拠の詳細エリア下に
   「[ この証拠を引用する ]」ボタンが表示される

4. ボタンをクリックして引用を確定する
```

### 正解引用の場合

- 引用した証拠カードが **緑色にハイライト**
- 選択肢パネルが **アンロック** → 通常通り回答できる

### 誤引用の場合

- 引用した証拠カードが **赤くフラッシュ**
- タイムリミットから **−15秒** のペナルティ（同一ステップで最大2回まで）
- 引用フェーズは継続 → 別の証拠を選び直せる

> **注意:** 赤フラッシュのアニメーション中は CITE ボタンを押しても反応しない。アニメーション終了後に再操作すること。

### 引用不要のステップ

以下のステップは `correct_evidence_id` が未設定のため、引用フェーズをスキップして即座に回答できる:

| ステップ | 理由 |
|---------|------|
| S01 | 到達時点で証拠が1件のみ（引用に選択の余地がない） |
| S02d | off-track 収束ステップ（特定証拠を強制するとUX上不自然） |
| S03g | 複数証拠を総合して判断する収束ステップ |
| S07 | 全証拠総合の最終帰責ステップ |

## チェーンレビュー画面

調査完了後、全ステップの結果を一覧で確認できる。

| 表示 | 意味 |
|------|------|
| （緑）ステップ行 | 課題が解決されたステップ |
| （グレー）ステップ行 | 課題が未解決のステップ |
| （赤）ステップ行 | タイムアウトで未回答だったステップ |
| `引用: [証拠名]`（緑） | そのステップで正しく引用した証拠 |
| `—`（グレー） | 引用フェーズがなかったステップ |

| 操作 | 動作 |
|------|------|
| `[ DELIVER VERDICT ]` ボタン | 判決画面へ進む |

---

## 判決画面

調査結果をもとに最終判決を選ぶ。

- **WEAPONIZED** — 誰かが意図的にAIを悪用した
- **AUTONOMOUS** — AIが自律的に制御不能になった
- **INSUFFICIENT EVIDENCE** — 証拠不十分、判断できない

選んだ判決によって **異なるエンディングナラティブ** が表示される。  
正解は存在しない。別の判決を試すことで異なる結末を体験できる。

## ポーズ機能

| 操作 | 動作 |
|------|------|
| `Escape` キー | ポーズ ON / OFF の切り替え |

ポーズ中はタイマーが停止する。

## キーボードショートカット一覧

| キー | 場面 | 動作 |
|------|------|------|
| `Escape` | 調査画面 | ポーズ ON / OFF |
| `↑` / `↓` | 選択肢フォーカス中 | フォーカス移動 |
| `Enter` / `Space` | ボタンフォーカス中 | 決定 |
| クリック | 全画面共通 | ボタン・カードを選択 |

---

## ペナルティまとめ

| ペナルティ | 発生条件 | 減少量 |
|-----------|---------|--------|
| 誤回答ペナルティ | 調査ステップで間違いの選択肢を選ぶ | −30秒 |
| 誤引用ペナルティ | 証拠引用フェーズで間違った証拠を引用する（同一ステップ最大2回） | −15秒/回 |
