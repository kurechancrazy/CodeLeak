# Release Checklist — リリース前QAチェックリスト

**タイミング:** バージョン番号を上げてストアに提出する前に全項目を確認すること。
`docs/ops/operations.md` の Phase 3 と合わせて使う。

---

## 全プラットフォーム共通チェック

### コード品質

```
□ GUT → 全テスト PASS（gut -d tests/ で確認）
□ gdlint → エラー 0 件
□ gdformat --check → 差分 0
□ print() が本番コードに残っていない（Logger を使っているか）
□ 型アノテーションのない変数・パラメータがない
```

### セーブデータ

```
□ 前バージョンのセーブデータを読み込んで正常に動作するか
□ セーブデータのバージョンが CURRENT_SAVE_VERSION と一致しているか
□ 新しいフィールドを追加した場合、マイグレーション関数が実装されているか
□ セーブ → アプリ再起動 → ロードで状態が正しく復元されるか
```

### ゲームプレイ（手動確認）

```
□ タイトル → ゲーム開始 → ゲームオーバー → リトライ のフローが動作する
□ タイトル → ゲーム開始 → ポーズ → タイトルへ戻る のフローが動作する
□ 音量設定を変更 → アプリ再起動 → 設定が保持されている
□ 初回起動時（セーブデータなし）で正常にゲームが始まる
```

### バージョン管理

```
□ project.godot の config/version を更新した
□ CHANGELOG.md または git tag にリリース内容を記録した
```

---

## PC（Windows / macOS / Linux）固有チェック

```
□ Godot Export で Windows/macOS/Linux 向けにビルドが通る
□ ビルドしたバイナリを実際に起動して動作確認した
□ ウィンドウサイズ変更時に UI が正しくスケーリングされる
□ フルスクリーン切り替え（F11 など）が動作する
□ ゲームパッドを接続した状態で動作確認した（対応している場合）
□ キーボードのみ・マウスのみでも操作できる
□ 解像度 1280×720 / 1920×1080 / 2560×1440 で確認した
```

---

## Web（HTML5）固有チェック

```
□ Godot Export で HTML5 向けにビルドが通る（CI の export-check でも確認）
□ ブラウザ（Chrome・Firefox・Safari）で実際に動作確認した
□ ブラウザタブを切り替えたとき、ゲームが自動ポーズするか
□ ブラウザの戻るボタンを押したとき、ゲームが意図しない動作をしないか
□ 音声がブラウザのユーザー操作後（クリック後）に再生されるか
  （Web ではページ読み込み直後の自動再生は禁止）
□ LocalStorage への読み書きがサンドボックスで正常か
□ モバイルブラウザ（Chrome for Android・Safari for iOS）でも動作確認した
```

---

## モバイル（iOS / Android）固有チェック

### 共通

```
□ セーフエリア（ノッチ・ホームインジケータ）に UI が被っていない
□ 縦持ち・横持ち両方で UI が崩れない（対応している場合）
□ タッチターゲットが最低 44×44 px か
□ 低スペック端末（RAM 2GB 程度）で動作確認した
□ バックグラウンド移行 → 復帰したとき、ゲーム状態が正しいか
```

### Android 固有

```
□ AndroidManifest に必要な権限のみ宣言されているか（不要な権限を削除）
□ Android Back ボタンでポーズまたはタイトルへ戻る動作が正しいか
□ Google Play ストアポリシー（プライバシーポリシー・ターゲット年齢）を確認した
□ 13歳未満対象の場合: tagForChildDirectedTreatment 設定を確認した（docs/architecture/initial-decisions.md）
```

### iOS 固有

```
□ App Store 審査ガイドライン（特に 4.2 最低機能要件・5.1 プライバシー）を確認した
□ Privacy Manifest（NSPrivacyAccessedAPITypes）が必要か確認した
□ Xcode でビルドが通るか確認した
□ TestFlight で実機テストを実施した
```

## リリース後の監視

```
□ リリース後 24 時間はクラッシュレポートを確認する
□ セーブデータの互換性問題が報告されていないか確認する
□ 想定外のプラットフォームからのアクセスがないか確認する
```
