# i18n — 多言語対応・日時フォーマット

## Godot の翻訳システム

Godot 4 はビルトインの翻訳システムを持つ。`.csv` または `.po` ファイルを使う。

---

## 翻訳ファイルのセットアップ

### CSVファイル（シンプルな場合）

```csv
keys,ja,en,zh
BUTTON_START,スタート,Start,开始
BUTTON_SETTINGS,設定,Settings,设置
BUTTON_QUIT,終了,Quit,退出
SCORE_LABEL,スコア: {score},Score: {score},得分: {score}
```

```
Project Settings → Localization → Translations → Add
→ assets/i18n/translations.csv
```

### 翻訳ファイルのパス

```
assets/
└── i18n/
    ├── translations.csv  ← メイン翻訳
    ├── ja.po            ← 日本語（.po形式の場合）
    └── en.po            ← 英語
```

---

## 翻訳の使い方

```gdscript
# ✅ tr() 関数で翻訳を取得
label.text = tr("BUTTON_START")

# ✅ 変数を含む翻訳
label.text = tr("SCORE_LABEL").format({"score": 1500})

# ✅ TranslationServer で言語を変更
func set_language(locale: String) -> void:
    TranslationServer.set_locale(locale)
    GameManager.update_setting("language", locale)
    # UIを再描画するシグナルを発行
    EventBus.settings_changed.emit("language", locale)

# ❌ 翻訳キーなしの直接文字列（禁止）
label.text = "スタート"  # 日本語固定 → 禁止
```

## 言語設定の保存と復元

```gdscript
# autoloads/game_manager.gd に追加
func _ready() -> void:
    var saved_locale: String = SaveManager.get_value("settings", "language", "ja")
    TranslationServer.set_locale(saved_locale)
```

## 日時フォーマット

```gdscript
# ✅ Godot の Time クラスを使う
var datetime: Dictionary = Time.get_datetime_dict_from_system()
var formatted: String = "%04d/%02d/%02d %02d:%02d" % [
    datetime.year, datetime.month, datetime.day,
    datetime.hour, datetime.minute
]

# ✅ ロケール対応の日付フォーマット
func format_date(unix_time: int) -> String:
    var dt: Dictionary = Time.get_datetime_dict_from_unix_time(unix_time)
    match TranslationServer.get_locale():
        "ja":
            return "%d年%d月%d日" % [dt.year, dt.month, dt.day]
        _:
            return "%04d/%02d/%02d" % [dt.year, dt.month, dt.day]
```

## RTL（右から左）言語対応

アラビア語・ヘブライ語等のRTL言語:

```gdscript
# Control ノードで RTL を有効化
control.layout_direction = Control.LAYOUT_DIRECTION_RTL

# または自動検出
if TranslationServer.get_locale() in ["ar", "he", "fa"]:
    control.layout_direction = Control.LAYOUT_DIRECTION_RTL
```
