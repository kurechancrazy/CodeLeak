## 1. ターゲット層と難易度方針

以下の質問に答えて方針を決める。決定した内容を `.kiro/steering/product.md` に追記すること。

### Q1. プレイヤー層はどちらに近いか？

| | カジュアル層 | コア層 |
|--|------------|-------|
| **1セッションの想定時間** | 5〜15分 | 30分以上 |
| **チュートリアルの量** | 多め（手取り足取り） | 少なめ（自分で発見） |
| **難易度曲線** | 緩やか・一定 | 急勾配・選択式 |
| **ゲームオーバーのペナルティ** | 少ない（すぐリトライ） | 重い（やり直しコスト） |
| **UIの情報量** | 少なく直感的 | 多く詳細 |

**決定:**
```
ターゲット層: [ カジュアル / コア / 両方（難易度選択） ]
チュートリアル方式: [ なし / ヒント表示 / 段階的チュートリアル / スキップ可 ]
難易度選択: [ なし / Easy-Normal-Hard / カスタム ]
```

### Q2. ゲームオーバー時のリトライペナルティはどうするか？

| | ノーペナルティ | 軽いペナルティ | 重いペナルティ |
|--|------------|------------|------------|
| **内容** | 即リトライ | ステージ最初から | セーブポイントから |
| **向いているジャンル** | アーケード・ランゲー | アクション・パズル | RPG・ローグライク |

**決定:** `リトライ形式: [ 即リトライ / ステージ最初から / セーブポイントから / チェックポイント ]`

## 2. 色覚多様性対応レベル

日本では約 5% の男性が色覚多様性を持つ。ゲームのジャンルと対象年齢に応じて対応レベルを決める。

### 対応レベルの選択

| レベル | 内容 | 対応コスト |
|-------|------|-----------|
| **最低限（推奨）** | 色だけで情報を伝える箇所に形状・アイコンを併用 | 小 |
| **中程度** | カラーブラインドモードを設定に追加 | 中 |
| **完全対応** | 全カラーパレットを色覚多様性に最適化したものに変更 | 大 |

**決定:** `色覚多様性対応: [ 最低限 / カラーブラインドモード搭載 / 完全対応 ]`

### 最低限対応のチェックリスト（全ゲームで実施）

```
□ HP残量の表示 → 数値またはハートアイコンを併用（赤だけに依存しない）
□ 敵の弱点表示 → アイコン・記号を使い、色だけで判断させない
□ ゲームオーバー / クリアの区別 → テキストを必ず表示する
□ 地雷・危険ゾーン → 形状（斜線・バツ印）を使う
```

## 3. 字幕・音声依存度の確認

重要な情報が音のみで伝わると、音なしでプレイするユーザーが不利になる。

### 確認チェック

```
□ 敵の攻撃予告が SFX のみで告知されていないか → 視覚的エフェクトも付ける
□ チュートリアルの説明が音声ナレーションのみでないか → テキストも表示する
□ ゲームオーバーの原因が音でしか分からない場面がないか
```

**決定:**
```
字幕システム: [ 不要 / テキスト表示のみ / フルサブタイトル ]
音声なしでも全情報が得られるか: [ Yes / No → 以下を修正 ]
  修正が必要な箇所:
```

## 4. 操作カスタマイズの有無

後から追加すると UI・保存設計の全面変更になるため、初期段階で決める。

### 対応レベルの選択

| レベル | 内容 | 実装コスト |
|-------|------|----------|
| **なし** | 固定キーバインド | 0 |
| **プリセット切り替え** | A/B/C タイプの選択肢 | 小 |
| **フルリマップ** | ユーザーが全キーを自由に変更 | 大 |

**決定:** `キーリマップ: [ なし / プリセット切り替え / フルリマップ ]`

### ゲームパッド対応範囲

```
決定:
□ ゲームパッド対応: [ 完全対応 / 部分対応 / 非対応 ]
□ 対応するコントローラー: [ Xbox / PS / Nintendo Switch / 全て ]
□ ゲームパッドのボタンラベル表示: [ 非対応 / Xbox統一 / 接続デバイスに応じて変更 ]
```

## 5. ゲームジャンル別 UX 最低要件

ゲームジャンルに応じて以下のセクションを確認する。

### アクション系

```
□ 入力からキャラ動作までの遅延が 1〜2 フレーム（16〜33ms）以内か
□ 攻撃・ジャンプに無敵フレームが必要か → [ Yes / No ]
□ 入力バッファ（直前入力の先行受付）が必要か → [ Yes / No ]
□ ヒットストップ（ダメージ時の一時停止）を実装するか → [ Yes / No ]
```

### パズル系

```
□ 「詰み」（解けない状態）を検出してリセット促すか → [ Yes / No ]
□ undo（手を戻す）機能が必要か → [ Yes（何手まで）: ___ / No ]
□ タイムアタック要素があるか → [ Yes / No ]
```

### RPG / アドベンチャー系

```
□ オートセーブを実装するか → [ Yes（タイミング: ___） / No（手動セーブのみ） ]
□ セーブスロット数 → [ 1 / 3 / 無制限 ]
□ 高速テキスト送り・スキップ機能が必要か → [ Yes / No ]
□ ミニマップが必要か → [ Yes / No ]
```

### ノベル / ビジュアルノベル系

```
□ テキスト表示速度をユーザーが変更できるか → [ Yes / No ]
□ オート進行（自動テキスト送り）が必要か → [ Yes / No ]
□ 既読スキップが必要か → [ Yes / No ]
□ バックログ（読み返し）が必要か → [ Yes / No ]
□ セーブポイントはどこか → [ どこでも / シーン切り替え時のみ / 手動 ]
```
