# Requirements — リザルト画面

## Project Description

レベルクリア後にスコア・ランク・タイム・ミス数を表示し、ハイスコア更新の演出を行うリザルト画面

---

## 1. 画面遷移

### 1.1 リザルト画面への遷移

- **1.1.1** `[SYSTEM SECURED]` 演出完了後、リザルト画面 (`scenes/ui/result_screen.tscn`) に遷移すること
- **1.1.2** 遷移時に スコア・ミス数・クリアタイム・ヒント使用数 をリザルト画面に渡すこと
- **1.1.3** GameState は `LEVEL_CLEAR` のまま遷移し、リザルト画面が受信した後に `RESULT` へ変更すること

### 1.2 リザルト画面からの遷移

- **1.2.1** `[RETRY]` ボタン押下時、リザルト画面はゲームプレイ画面 (`game_screen.tscn`) へ遷移すること
- **1.2.2** `[MAIN MENU]` ボタン押下時、リザルト画面はメインメニュー (`main_menu.tscn`) へ遷移すること
- **1.2.3** `confirm` アクション（Enter/Space）押下時、`[RETRY]` と同じ動作をすること
- **1.2.4** `cancel` アクション（Escape）押下時、`[MAIN MENU]` と同じ動作をすること

---

## 2. スコア・結果表示

### 2.1 基本情報の表示

- **2.1.1** リザルト画面はレベルタイトル（例: `"The Obedient Liar"`）を表示すること
- **2.1.2** リザルト画面はバグ種別（例: `[BACKDOOR]`）を表示すること
- **2.1.3** リザルト画面は最終スコアを整数値で表示すること（例: `SCORE: 1000`）
- **2.1.4** リザルト画面はランク（`S` / `A` / `B` / `C` / `D`）を大きく表示すること
- **2.1.5** リザルト画面はクリアタイムを `MM:SS` 形式で表示すること
- **2.1.6** リザルト画面はミス数を整数値で表示すること（例: `MISS: 2`）
- **2.1.7** リザルト画面はヒント使用数を整数値で表示すること（例: `HINTS USED: 1`）

### 2.2 タイプライター演出

- **2.2.1** 画面表示時、各結果項目がタイプライター形式で順に出現すること（項目ごとに 100ms 間隔）
- **2.2.2** タイプライター演出中、ボタン操作は受け付けないこと
- **2.2.3** タイプライター演出の総所要時間は 2 秒以内であること

---

## 3. ハイスコア更新

### 3.1 ハイスコア比較

- **3.1.1** リザルト画面は SaveManager の保存済みスコアと今回スコアを比較すること
- **3.1.2** 今回スコアが保存済みスコアを上回る場合、`>> NEW HIGH SCORE!` を表示すること
- **3.1.3** 初回クリア（スコア未登録）の場合も `>> NEW HIGH SCORE!` を表示すること

### 3.2 ハイスコア演出

- **3.2.1** ハイスコア更新時、`>> NEW HIGH SCORE!` テキストが点滅アニメーション（0.5秒周期）すること
- **3.2.2** ハイスコア更新時、スコア表示色を通常色（`#00ff41`）からゴールド（`#ffd700`）に変えること

---

## 4. 視覚スタイル

### 4.1 サイバーパンク端末デザイン

- **4.1.1** 背景色は `#0d0d0d`（ほぼ黒）であること
- **4.1.2** テキスト基本色は `#00ff41`（端末グリーン）であること
- **4.1.3** ランク文字はフォントサイズ 72px 以上で中央に大きく表示すること
- **4.1.4** 画面タイトルとして `// ANALYSIS COMPLETE` を最上部に表示すること
- **4.1.5** 結果項目はモノスペースフォントで表示すること

### 4.2 ボタンスタイル

- **4.2.1** `[RETRY]` ボタンと `[MAIN MENU]` ボタンはフラットスタイル（枠なし）で表示すること
- **4.2.2** ボタンホバー時にテキスト色が白（`Color.WHITE`）に変わること
- **4.2.3** タイプライター演出完了後にのみボタンが表示されること

---

## 5. データ永続化

### 5.1 スコア保存

- **5.1.1** リザルト画面は表示時に SaveManager 経由でハイスコアを保存すること（SaveManager の既存ロジックに委ねる）
- **5.1.2** 保存処理はタイプライター演出と並行して非同期で行われること（演出をブロックしない）
