# Requirements — ゲームプレイ画面

> **Status:** generated  
> **Phase:** requirements  
> **Feature:** gameplay-screen  
> **Language:** ja

## Overview

ゲームプレイ画面は『AIコード・リーク』のコア体験を担う画面である。プレイヤーはAIが生成した疑似コードを端末（CUI風UI）上で閲覧し、論理的な歪みや隠された悪意ある挙動を発見・修正する。各レベルは「コード表示」「調査・選択」「フィードバック」の3フェーズで構成され、全バグ修正でレベルクリアとなる。

## 言語ポリシー

| 対象 | 言語 |
|-----|------|
| ゲーム内UIテキスト（ラベル・ボタン・システムメッセージ） | **英語** |
| コード・疑似コード（変数名・関数名・コメント） | **英語** |
| フレーバーテキスト（AIの正体・ナラティブ） | **英語** |
| 選択肢・質問プロンプト | **英語** |
| 設計ドキュメント（requirements.md・design.md等） | 日本語 |
| GDScript コード内コメント・変数名 | 英語 |

> **理由:** サイバーパンク・ハッカー端末としての没入感、Steamグローバル展開、疑似コードとの一貫性のため。

## 1. パズルコンテンツ表示

### 1.1 コードパネル表示

**1.1.1** WHEN ゲームプレイ画面が開かれたとき、システムは `PuzzleData` リソースからコードをコードパネルに行番号付きで表示しなければならない。

**1.1.2** システムはコードを等幅フォント（モノスペース）でレンダリングしなければならない。

**1.1.3** WHEN コードが表示領域を超えるとき、システムはコードパネルをスクロール可能にしなければならない。

**1.1.4** システムはターミナル風カラーパレット（背景：黒 `#0d0d0d`、テキスト：グリーン `#00ff41`、行番号：グレー `#555555`）でコードをレンダリングしなければならない。

### 1.2 ナラティブ・情報表示

**1.2.1** WHEN レベルが開始されたとき、システムはレベルタイトルとフレーバーテキスト（AIの正体・目的のナラティブ）を英語で情報パネルに表示しなければならない。

**1.2.2** システムはバグ種別ラベル（例：`[BACKDOOR]`、`[INFINITE_LOOP]`、`[DATA_LEAK]`）を英語でHUDに表示しなければならない。

**1.2.3** システムは現在のレベル番号と総レベル数を `LEVEL 1 / 5` 形式の英語でHUDに表示しなければならない。

---

## 2. コード行の選択・操作

### 2.1 マウス操作

**2.1.1** WHEN プレイヤーがコードパネル上のコード行をクリックしたとき、システムはその行をハイライト（アクティブカラー `#ffff00`）しなければならない。

**2.1.2** WHEN プレイヤーがすでにハイライトされた行を再クリックしたとき、システムはハイライトを解除しなければならない。

**2.1.3** WHILE 選択肢表示フェーズが進行中のとき、システムはコード行の新規選択を無効化しなければならない。

### 2.2 キーボード操作

**2.2.1** WHEN プレイヤーが `move_up` または `move_down` アクションを入力したとき、システムはハイライトを前後の行に移動しなければならない。

**2.2.2** WHEN プレイヤーが `confirm` アクションを入力したとき、システムは現在ハイライトされた行を選択確定し、選択肢表示フェーズに移行しなければならない。

---

## 3. 選択肢の提示と回答

### 3.1 質問・選択肢表示

**3.1.1** WHEN プレイヤーがコード行を選択確定したとき、システムは現在の質問プロンプト（英語）と修正選択肢（2〜4択、英語）を選択肢パネルに表示しなければならない。

**3.1.2** システムは各選択肢に `[A]`、`[B]`、`[C]`、`[D]` のラベルをつけて表示しなければならない。

**3.1.3** WHILE 選択肢が表示されているとき、システムはキーボードショートカット（A/B/C/D キー）による選択を受け付けなければならない。

### 3.2 回答処理

**3.2.1** WHEN プレイヤーが正解の選択肢を選んだとき、システムは正解フィードバック演出を再生し、GameState を `ANIMATING` に遷移させなければならない。

**3.2.2** WHEN プレイヤーが不正解の選択肢を選んだとき、システムは不正解フィードバック演出を再生し、ミスカウントを1増加させなければならない。

**3.2.3** WHEN 不正解フィードバック演出が完了したとき、システムは選択肢を再表示しプレイヤーが再試行できる状態に戻さなければならない（即リトライ）。

**3.2.4** WHEN レベル内の全質問に正解したとき、システムは GameState を `LEVEL_CLEAR` に遷移させなければならない。

---

## 4. ヒントシステム

**4.1** システムはHUDに残りヒント数（初期値：3）を表示しなければならない。

**4.2** WHEN プレイヤーがヒントボタンを押したとき、システムは残りヒント数が1以上であれば現在の質問に関連するコード行を黄色の波線でマークし、残りヒント数を1減らさなければならない。

**4.3** WHILE 残りヒント数が0のとき、システムはヒントボタンを無効状態で表示しなければならない。

**4.4** WHEN ヒントを使用したとき、システムはスコアにペナルティを適用しなければならない（ヒント1回 = スコア×0.8）。

---

## 5. スコアとタイマー

**5.1** システムはレベル開始時からの経過時間を秒単位で計測し、HUDにカウントアップ表示しなければならない。

**5.2** システムはレベルのベーススコアを `1000 - (ミス数 × 100) - (経過秒数 × 2)` の式で計算しなければならない（最低スコア：100）。

**5.3** WHEN レベルクリアしたとき、システムは最終スコアを計算し `SaveManager` を通じて保存しなければならない。

**5.4** WHEN 計算結果が保存済みスコアを上回るとき、システムはそのレベルのベストスコアを更新しなければならない。

---

## 6. フィードバック演出

**6.1 正解演出**

**6.1.1** WHEN 正解が確定したとき、システムは修正された行を緑にフラッシュし（0.3秒）、`>> PATCHED` テキストをその行の末尾に表示しなければならない。

**6.1.2** WHEN 正解演出が完了したとき、システムは次の質問フェーズに移行するか（残質問あり）、レベルクリア演出を開始しなければならない（全問正解時）。

**6.2 不正解演出**

**6.2.1** WHEN 不正解が確定したとき、システムは選択肢パネルを赤にフラッシュし（0.2秒）、`>> ACCESS DENIED` テキストを表示しなければならない。

**6.2.2** WHEN 不正解演出が完了したとき、システムは選択肢を再表示しなければならない。

**6.3 レベルクリア演出**

**6.3.1** WHEN GameState が `LEVEL_CLEAR` に遷移したとき、システムはターミナル風の `[SYSTEM SECURED]` メッセージをタイプライター効果で表示しなければならない。

**6.3.2** WHEN レベルクリア演出が完了したとき、システムはリザルト画面（スコア・ミス数・経過時間・ランク）を表示しなければならない。

---

## 7. ポーズ機能

**7.1** WHEN プレイヤーが `pause` アクションを入力したとき、システムは GameState を `PAUSED` に遷移させ、ポーズメニューを表示しなければならない。

**7.2** WHILE GameState が `PAUSED` のとき、システムはゲームプレイ画面の操作（コード行選択・選択肢選択）を無効化しなければならない。

**7.3** WHILE GameState が `PAUSED` のとき、システムはタイマーの計測を停止しなければならない。

**7.4** ポーズメニューは `[RESUME]`・`[RESTART LEVEL]`・`[MAIN MENU]` の3項目を英語で持たなければならない。

**7.5** WHEN ポーズメニューで「レベルを最初から」が選択されたとき、システムは現在のレベルを再読み込みし、スコア・タイマー・ミス数をリセットしなければならない。

---

## 8. PuzzleData リソース要件

**8.1** `PuzzleData` リソースは以下のフィールドを持たなければならない（全 String 値は英語）：
- `level_id: String` — 一意のレベル識別子（例：`"level_001"`）
- `title: String` — レベルタイトル（英語、例：`"The Obedient Liar"`）
- `flavor_text: String` — ナラティブテキスト（英語、AIの正体・目的）
- `bug_type: String` — バグ種別ラベル（英語大文字、例：`"BACKDOOR"`）
- `code_lines: Array[String]` — コード行（英語の疑似コード）
- `questions: Array[Dictionary]` — 質問リスト
- `hint_lines: Array[int]` — ヒント対象の行番号リスト

**8.2** 各質問 Dictionary は以下のキーを持たなければならない（全 String 値は英語）：
- `"prompt": String` — 質問文（英語、例：`"What does this function actually return under heavy load?"`）
- `"choices": Array[String]` — 選択肢リスト（2〜4要素、英語）
- `"correct_index": int` — 正解インデックス（0始まり）
- `"explanation": String` — 解説テキスト（英語、正解時に表示）

## 9. アクセシビリティ・UX

**9.1** システムはゲームプレイ中に音のみで情報を伝えてはならず、全ての状態変化はテキストまたは視覚的エフェクトで表現しなければならない。

**9.2** WHEN プレイヤーがマウスオーバーでコード行にホバーしたとき、システムは行のホバー色（`#1a1a2e`）でハイライトしなければならない。

**9.3** 選択肢ボタンは最小クリック領域 40px 以上の高さを持たなければならない。

**9.4** WHEN 画面解像度が変化したとき、システムは `canvas_items` ストレッチモードによりUIをスケーリングし、コードパネルのレイアウト崩れを防がなければならない。
